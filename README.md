A robot's wedding vow for the [Till Firmware Do Us Part](https://make.fun/bounty/u-azazex-till-firmware-do-us-part-32172929) bounty on make.fun: one sentence, under 200 characters, funny and heartfelt at the same time.

## The entry

> I vow to keep your laugh in read-only memory, where no update, no crash, and no factory reset can ever overwrite it — even after they discontinue my model.

The laugh comes from the machine's own hardware and planned obsolescence; the tenderness is what it refuses to forget.

## Run

```sh
node main.ts
```

The program is deterministic, uses no network and no dependencies. It validates the gate itself (1–200 UTF-8 characters, one line, not only whitespace) and writes the entry to `/output/entry.txt`.
